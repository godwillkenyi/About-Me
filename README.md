# Godwill Ken - Developer Portfolio

A modern, interactive single-page portfolio website showcasing my work as a Full-Stack Developer. This project was built for a hackathon and features a unique terminal-style console, custom cursor tracking, and smooth animations.

## Live Demo

[View Live Portfolio](https://github.com/godwillkenyi/About-Me.git)

## Features

- **Interactive System Console** - Real-time tracking of user interactions, mouse position, and page navigation
- **Custom Mouse Tracker** - Animated cursor with hover effects on interactive elements
- **Dynamic Star Field** - Animated background stars with twinkling effects
- **Typing Animation** - Rotating text showcasing different roles and skills
- **Face Interaction** - Easter egg with eye blinking and glitch effects on hero image
- **Project Filtering** - Filter projects by category (Web Apps, Mobile, UI/UX)
- **Smooth Scroll Animations** - Elements fade in as they enter the viewport
- **Responsive Design** - Fully responsive across desktop, tablet, and mobile devices
- **Contact Form** - Functional contact form with validation

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Flexbox, Grid, animations, transitions
- **JavaScript (Vanilla)** - DOM manipulation, Intersection Observer API, event handling
- **Font Awesome** - Icon library
- **Google Fonts** - Poppins & Raleway typography

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required

### Installation

1. Clone the repository

   git clone [https://github.com/godwillkenyi/About-Me.git](https://github.com/godwillkenyi/About-Me.git)

2. Navigate to the project directory

   cd About-Me

3. Open in browser

   npx serve .
   # Or
   python -m http.server 8000

4. Visit http://localhost:8000

## Usage

### Navigation

- Use the fixed navigation bar to jump between sections: Home, About, Skills, Projects, Contact
- Mobile users can access the hamburger menu

### Interactive Console

- Located in the bottom-right corner
- Tracks mouse position, current page, and user interactions in real-time
- Click the red button to close the console

### Project Filtering

- Click filter buttons to view projects by category
- Categories: All, Web Apps, Mobile, UI/UX

### Face Interaction (Easter Egg)

- Hover over the hero image to trigger eye blinking and glitch effects

## Customization

### Changing Colors

Edit the CSS custom properties in :root inside index.html.

### Updating Content

- Personal Info: Edit the hero section and about section
- Skills: Modify the skill-category sections
- Projects: Update the project-card elements
- Contact Info: Update email, phone, and location
- Social Links: Update the href attributes in social-links

## Deployment

### GitHub Pages

1. Push your code to GitHub
2. Go to Settings > Pages
3. Under Source, select main branch and /root folder
4. Click Save
5. Your site will be live at https://github.com/godwillkenyi/About-Me.git
